# iot‑professional‑qa‑assistant
物联网RAG问答助手 | 大模型命令行多轮对话程序

## 📝项目简介
基于 OpenAI 兼容接口封装通义千问大模型，实现**命令行多轮对话助手**。限定物联网领域回答范围，自带对话上下文管理、输入校验、异常捕获、上下文裁剪，防止prompt超长；可直接对接FastAPI封装为Web接口，扩展RAG向量检索能力。

## ✨功能特性
1. **大模型封装**：兼容阿里云DashScope通义千问OpenAI兼容接口，封装`llm_ask()`通用调用函数
2. **领域约束**：System Prompt限定仅回答物联网、嵌入式、传感器、单片机、Python开发相关问题，无关问题拒绝回答，禁止编造答案
3. **多轮上下文对话**：维护完整对话历史，记忆多轮聊天内容
4. **上下文自动裁剪**：超过指定轮数自动截断历史，避免输入token超限
5. **输入合法性校验**：过滤空输入；支持`quit / exit / 退出`指令正常结束程序
6. **异常捕获**：网络、接口调用异常捕获，返回可读错误信息，程序不会直接崩溃
7. 低temperature=0.2，输出结果偏向稳定、事实性回答，适合技术问答场景

## 🛠技术栈
- Python 3.10
- openai（使用DashScope兼容模式调用通义大模型）

修改代码内全局配置：

```bash

```

### 4. 使用交互
- 在控制台直接输入物联网相关技术问题
- 输入 `quit` / `exit` / `退出` 结束对话程序

## 💡核心函数说明
### `llm_ask(user_prompt, system_prompt)`
> 底层大模型调用封装函数
- 参数：用户提问，系统角色提示词
- 返回：模型回答文本；发生网络/接口异常返回错误描述字符串
- 设置15s超时时间，防止请求卡死

### `chat_assistant()`
> 多轮对话主逻辑
1. 初始化system领域角色规则
2. while循环读取控制台用户输入，做空输入、退出指令判断
3. 维护对话`history`列表保存上下文
4. 历史消息数量超限自动裁剪，保留system+最近多轮对话，规避上下文溢出

## 🔧可扩展方向
1. 接入Chroma向量数据库，增加RAG检索，结合知识库做问答
2. 使用FastAPI包装函数，对外提供HTTP接口，搭建Web服务
3. 增加对话持久化，把聊天记录保存本地json文件
4. 增加流式输出，实现打字机效果返回回答

## 🐛注意事项
1. `temperature=0.2`，适合技术问答；创意生成场景可以适当调高数值
2. 上下文裁剪逻辑：防止累计对话token过大造成接口报错
3. 网络异常会捕获异常直接返回提示，不会直接终止程序
4. API密钥严禁上传公开代码仓库
